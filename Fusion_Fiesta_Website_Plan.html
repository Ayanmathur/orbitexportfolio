Page 03 · Cuisine
CUISINE & DRINK — THE EXPERIENCE SELL
Main Page

Purpose

Not the menu — this page sells the experience and style of each cuisine category. Full-bleed photos, short evocative descriptions, emotional language. Think of it as the "cinema trailer" before the full menu PDF.

🍛 Indian Fusion

Describe: how classic Indian flavours meet modern plating and technique. 2–3 sentences, sensory language.
📌 TYPE: Hero dish photo — a signature Indian fusion plate, styled

🍝 Continental

Rustic European comfort meets Nagpur hospitality. Pasta, risotto, grills. Describe the mood of the continental section.
📌 TYPE: Styled continental dish — pasta / steak / grilled protein

🥢 Asian / Oriental

Wok-tossed, umami-rich, vibrant. Thai, Chinese, Japanese-inspired. Express the energy of Asian cooking.
📌 TYPE: Noodle dish or sushi-style plate, vibrant colours

🍸 Signature Cocktails

Craft cocktails and mocktails — the bar identity. Name the signature drink & describe the flavour story.
📌 TYPE: Cocktail pour, bar back-lit shot, garnish close-up

🍰 Desserts

Artisan endings. Fusion desserts — give the section a poetic one-liner. E.g. "Every meal deserves a final encore."
📌 TYPE: Dessert plating close-up, warm lighting

☕ Beverages

Hot beverages, specialty teas, fresh juices. The non-alcoholic experience — equally curated.
📌 TYPE: Coffee/tea flat-lay, warm toned

Layout Direction

Alternating full-bleed left/right image-text sections (like hitchki.co's cuisine panels). Each cuisine: large photo on one side, headline + 3-line description + "View Menu" button on the other. CTA at bottom: "Explore Our Full Menu →" → links to Menu Page.

Dish Reservation System — Core Mechanic

50 dishes total. Each dish has a fixed number of available "slots" (e.g. 3 slots per dish). When all slots for a dish are taken, it greys out and shows "Fully Booked" — late arrivals cannot pick that dish. This creates urgency and FOMO. Below is how it looks:

Developer Note — Dish Booking Logic

Each dish has a configurable slot limit (default: 3). On booking, slot count decrements in real-time (Firebase / Supabase recommended for live updates). When count = max, dish card automatically adds class .grey and disables button. A real-time listener pushes updates to all open sessions — so if someone else books while you're browsing, the count updates live without refresh. Admin panel to add/edit/remove dishes and reset slot counts.

Design Reference
COLOR PALETTE · TYPOGRAPHY · STYLE

Design Philosophy

Bold, dark, flavour-forward — the energy of a premium lounge, not a family dhaba. Flame red + gold = heat, desire, premium dining. Dark near-black = sophistication, nightlife, exclusivity. Teal = a calm counterpoint for CTA buttons (stands out against the warm palette). The look is hitchki.co's boldness with a Nagpur-specific warmth.
