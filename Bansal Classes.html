Build pattern for future events

Use this exact card structure for every future seminar: title + tag → date/venue/time-slots → 3–4 topic chips → format line (joint session, Q&A, food, takeaway) → price → WhatsApp CTA + QR code. Below the flagship card, add a smaller "Past Seminars" strip — photos + turnout numbers from previous events build credibility for the next one.

💡Tone tip: your existing seminar script already balances urgency with real value (expert panel, practical takeaways) — keep that. For the webpage version specifically, pair every "risk" topic chip with a visible "here's how we help" resolution nearby, so the page reads as supportive rather than purely alarming. Reuse the full WhatsApp script as-is for the actual broadcast; this card is just the condensed web version.

Design Reference
Color Palette, Typography & Style Guide

Design Philosophy

Deep maroon + gold — the classic, instantly-recognisable palette of serious Indian coaching brands (achievement, urgency, trust). Bold, modern sans-serif type instead of an elegant script, since the emotional target is energy and results, not luxury calm. Clean white/cream space so result numbers and topper photos stay the visual focus.
