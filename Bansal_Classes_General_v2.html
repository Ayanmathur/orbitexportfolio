📌 Research & data-accuracy note — please read before development: "Bansal Classes" is run as an independently-managed franchise model — several unrelated businesses also trade under the "Bansal Classes" name in different cities, with no connection to the original Kota-founded brand. Because of this, only facts confirmed on the official national site bansalclasses.in are used as verified brand content below: founding year, founder, official course names (BULL'S EYE / NUCLEUS / STERLING / Pre-Foundation), the BAITS test series, the BOOST scholarship test, and the DLP program. Everything specific to a particular centre — address, phone number, fee structure, faculty names, local results, director name, and centre photography — is left as a clearly-marked [Centre Name] / TBD placeholder rather than guessed, so this plan can be safely reused as the base for any individual Bansal Classes location without ever risking another centre's data being put in the wrong place. Whoever adapts this for a specific centre should fill in those placeholders — and add the two optional per-centre modules — with that centre's own confirmed details.

Design Reference
Color Palette, Typography & Style Guide

Design Philosophy

A blue, light-blue, white & grey palette — built to match bansalclasses.in's own brand direction, and to read as trustworthy, academic, and forward-looking rather than loud. The brightest blue is reserved almost entirely for CTAs and conversion points (buttons, sticky bar, brochure download), so a visitor's eye is always pulled toward the next action — book a demo, enquire now, know more — instead of getting lost in decoration. Bold sans-serif type keeps the energy active; generous white/light-blue space keeps result numbers and topper photos the visual focus.

Conversion Reference
Call-to-Action Wording — Keep It Consistent

Why this matters

Every CTA on the page should come from this short, consistent set — mixing in new button text section-to-section makes a page feel improvised and dilutes which action actually matters most. Three buttons do all the work:

🎯 Book Free Demo Class

The primary action everywhere — navbar, hero, sticky bar, results wall, contact form. Brightest blue, largest button on the page.

💬 Enquire Now

The fast, low-friction action — WhatsApp bubble, event cards, course cards. One tap, no form to fill.

ℹ️ Know More

The soft, exploratory action — course cards, "Why Bansal" section, secondary hero button. For visitors who aren't ready to commit yet.

⬇️ Download Brochure

A low-commitment fallback for visitors who want to think it over — footer, end of admission-process section.

Template Usage
How to Adapt This for a Specific Centre

Step-by-step

1. Replace every [Centre / City], [Centre Name], and [City] placeholder with that centre's real name and location.
2. Collect and insert all TBD items flagged above — address, phone, rankers, photos — directly from that centre's franchise owner. Never copy these from a different centre's listing or a third-party directory site, even if the name matches.
3. Add a state-specific course (e.g. a local CET) in §3 only if relevant to that state.
4. Keep the official course names, BOOST, BAITS, and DLP branding exactly as shown — these are confirmed national Bansal Classes terms and should not be altered per centre.
5. Add the two optional modules below — Meet Our Faculty and Centre Director Strip — once that centre's real people, photos and consent exist. Insert Faculty after §5 Results and before §6 Events; insert the Director Strip as a bottom strip below §11 Footer, exactly as in this reference.
6. Hand the finished, filled-in version to the designer/developer along with real logo files and brand assets.
